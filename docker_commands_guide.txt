Лабораторна робота №2
Послідовність команд для виконання
============================================

1. Перевірка наявності Docker та запуск Docker Desktop:
   brew install --cask docker  (якщо не встановлено)
   open -a Docker

2. Збірка та запуск контейнерів за допомогою сучасного docker compose:
   docker compose up --build -d

3. Перевірка запущених контейнерів:
   docker ps

4. Перевірка логів FastAPI контейнера:
   docker logs fastapi_app

5. Перевірка логів PostgreSQL контейнера:
   docker logs postgres_db

6. Перевірка роботи API:
   curl -s http://localhost:8000/
   curl -s http://localhost:8000/hello/Illia

7. Перегляд встановлених бібліотек всередині контейнера FastAPI:
   docker exec fastapi_app pip list

8. Зупинка контейнерів:
   docker compose down
